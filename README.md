一、信息处理原则
超咔是一款在本机处理照片的工具，没有注册账号、广告、用户跟踪或应用后端。应用未申请联网权限，不将照片、编辑配方或识别结果上传给开发者。

应用市场、操作系统及系统文件选择器的独立数据处理，适用相应服务提供方的隐私政策。
二、相机、照片与文件权限
相机权限（ohos.permission.CAMERA）
仅在你主动使用拍照功能时申请，用于取景、拍摄和实时滤镜。应用不请求麦克风权限。拒绝相机权限不影响编辑已有照片。

照片和视频读取权限（ohos.permission.READ_IMAGEVIDEO）
仅在你主动开启“设备相册整理”并确认范围后申请。该系统权限名称包含视频，但本应用只处理图片，不读取视频内容。

授权后，应用遍历设备相册照片，自动分类并建立本地搜索索引，同时监听相册变化以提示更新。整理仅在前台主动进行，可以暂停和继续。拒绝此权限，仍可通过系统照片选择器选择指定照片修图。

你选择导入的照片会复制到应用私有空间，用于非破坏性编辑和保存草稿。保存作品或导出备份由你主动发起，并使用系统授权界面。编辑器不会覆盖原有系统照片。
三、端侧 AI 与编辑数据
离线照片分类默认关闭，由你选择开启。应用内置 EfficientNet-Lite0 内容分类和 YuNet 人脸检测模型，在本机运行，不联网下载模型，不依赖系统 AI 分类服务。

应用可能在私有空间保存照片分类标签、搜索关键词、相似构图特征、收藏、相册名称，以及人像编辑所需的人脸位置和手动控制点。这些数据不上传，不用于识别真实身份，不进行人脸身份比对。

分类和搜索基于模型标签及中英文关键词，不是通用图文语义检索，也不提供 OCR 文字提取。结果可能不准确，已导入照片可手动纠正分类。关闭分类会停止后续扫描，但不会自动删除已有分类结果。

设备相册整理只保存系统照片引用、名称、时间、分类和关键词，不批量复制或删除系统照片。进入编辑时，才单独导入照片副本。“关闭整理并清除索引”不会删除系统照片、已导入原图或草稿。设备整理索引不包含在草稿备份中，可在重新授权后重建。
四、拍摄信息与字体
仅在你主动启用拍摄信息边框时，应用读取相机、镜头、焦距、光圈、快门、ISO 和拍摄时间等字段。不为该功能读取 GPS 或设备序列号。你选择显示的字段会作为可见文字进入导出作品。

导入字体只复制到应用私有空间，SHA-256 用于本地内容去重，字体不会上传。请确认所使用字体和图片素材具有相应使用许可。
五、保存、备份与清理
草稿、导入原片、素材、字体、识别结果和数据库索引保存在本机。

你主动导出的 .csbackup 备份未加密，包含原片、当前草稿、风格及依赖素材和字体。原片按字节保存，可能保留原有 EXIF/GPS 信息，请保存在可信位置。操作系统可能同步你选择的存储位置，这不属于应用上传行为。备份不包含导出队列、撤销历史、设置或已导出作品。

恢复备份前会校验文件，确认后新增副本，不覆盖已有草稿。素材清理先移入私有可恢复区，满七天后仍需你主动确认才能永久清理，不会删除原片或系统相册照片。
六、第三方与系统组件
应用使用 OpenCV 本地图像处理代码、EfficientNet-Lite0 和 YuNet 端侧模型，以及鸿蒙相机、媒体库、文件、图像、MindSpore Lite CPU 推理、数据库和界面等系统能力。

应用未接入第三方广告、统计、支付、社交登录或云端 AI SDK，不包含联网分析或遥测。模型来源、版本、许可证及声明可在应用设置中查看。
七、你的选择与数据删除
你可以在系统设置中撤回相机或图库权限，也可以关闭应用内识别功能，取消导入、导出或备份。拒绝可选权限不影响其他不依赖该权限的功能。

可通过系统的应用数据清理功能或卸载，删除全部应用私有数据。此操作不可撤销，请先导出需要保留的作品或备份。系统相册中的作品、已导出的备份及其他外部文件不会随卸载自动删除，需自行另行处理。应用没有账户，无需注销账户。

如需了解、纠正或删除与你主动反馈有关的信息，请联系上述邮箱。我们仅使用你主动发送的联系方式和问题内容回复及排查，不主动收集诊断日志。请勿发送不必要的原始照片、证件、人脸图片或备份文件。
八、未成年人、政策变更与联系
本应用不专门面向儿童，不提供社交或公开发布功能。未成年人应在监护人指导下使用，避免导出或分享含个人信息的照片。

如未来增加联网、账号或其他数据用途，我们会先更新政策，并按适用要求告知，不以本政策授权未说明的处理。
